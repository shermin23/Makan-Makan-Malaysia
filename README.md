# 🍽️ **Makan-makan Malaysia**

A web-based platform designed to introduce, showcase, and celebrate the diverse world of Malaysian cuisines. This website aims to help users explore local dishes, discover regional food traditions, and learn how to prepare authentic Malaysian meals. Originally developed as a collaborative project for a group assignment, **my personal contributions focus on the Home & Recipe page**.

---

## 🛠️ **Tech Stack**

**Frontend:** HTML, CSS, JavaScript
**Tools:** Git, GitHub

---

## 🚀 **Getting Started**

Follow the steps below to set up and run the application locally.This is a webpage for foreigners and Malaysians to know more about Malaysian cuisines


Steps to set restful API:
1. open cmd prompt
2. cd the file path of recipe-api (cd Document\...\recipe-api)
3. type: npm init -y 
4. type: npm install express body-parser cors
5. type: node server.js 
6. dont close cmd promt & run the html
